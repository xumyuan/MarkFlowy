Issue: WYSIWYG editor completely non-functional
  • No cursor visible when clicking in editor
  • Cannot type text
  • Cannot select text
  • No editing capability at all

Root Cause: EditorState naming conflict
  • Project defined its own EditorState class for Riverpod state management
  • appflowy_editor library also uses EditorState as internal class
  • Naming conflict caused ambiguity during type resolution
  • Editor's internal state management failed completely

FIX #1: EditorState → AppEditorState (P0 - CRITICAL)

File: lib/providers/editor_provider.dart

BEFORE:

    final EditorMode mode;

  }
